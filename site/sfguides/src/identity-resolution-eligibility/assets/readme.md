# Assets

Demo files for the Identity Resolution and Eligibility quickstart.

| File | Description |
|------|-------------|
| `Lab_Script.sql` | Builds the `KEYSTONE_DEMO` database: synthetic data, identity resolution, eligibility, Dynamic Tables, masking, sharing, semantic view, and Cortex Agent |
| `KEYSTONE_CASEWORKER.sv.yaml` | Semantic view definition used by the Cortex Agent |
| `keystone-console.zip` | Next.js caseworker app for Snowflake App Runtime (deploy with `snow app deploy`) |
